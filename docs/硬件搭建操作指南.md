# FlowCC 硬件搭建操作指南

> 目标：把一台普通直流小风扇改造成 FlowCC 智能风扇，
> 支持 USB 串口 / WiFi / 蓝牙三种连接，桌面挂件与控制中心均可控制。
> 全程低压直流（5V/12V），认真核线即可安全完成。预计耗时 1~2 小时。

## 一、物料清单（BOM）

| 物料 | 规格建议 | 数量 | 参考价 | 说明 |
|---|---|---|---|---|

| 续流二极管 | 1N4007 | 2 | ¥0.5 | 吸收反电动势，必装 |

## 二、接线图

```
            风扇正极 ──────────────── 电源正极(5V/12V)
               │
            [1N4007]  阴极(色环)朝电源正
               │
  ESP32        ├─ 风扇负极 ─ MOSFET 漏极(D)
  GPIO25 ─[1kΩ]─ MOSFET 栅极(G)
               │     MOSFET 源极(S) ─ GND
          [10kΩ]下拉到 GND
  GND ──────────────────────────── 电源 GND（共地！）
  GPIO26 ─ 舵机信号线(橙)   舵机红─5V  舵机棕─GND
  5V 风扇可由 ESP32 USB 的 5V 取电（电流≤0.5A）
```

口诀：**先共地，后供电；二极管方向别接反；栅极下拉不能省。**

## 三、搭建步骤

1. **面包板预搭**：按上图在面包板上接好 MOSFET 调速回路，暂不接舵机。
2. **核线**：万用表通断档核对 GND 连通、正负无短路；二极管色环朝向电源正。
3. **烧录固件（串口版）**：
   - 安装 Arduino IDE 2.x → 开发板管理器搜 `esp32 by Espressif Systems` 安装（≥3.0）。
   - 打开 `firmware/esp32_fan/esp32_fan.ino`，确认 `#define FLOWCC_TRANSPORT SERIAL`。
   - USB 连接 ESP32，选板 `ESP32 Dev Module` 与对应端口，上传。
   - 串口监视器 115200，按复位应见 `HELLO FLOWCC 1.3`。
4. **手动验固件**：监视器发 `PWR 1` 风扇应转；`SPD 3` 明显加速；`PWR 0` 停转。
   不转则查：MOSFET 方向、共地、风扇好坏（直接电源试）。
5. **接舵机**：GPIO26/5V/GND 接 SG90，发 `OSC 1` 应开始左右扫；`ANG 30` 应转向左侧。
6. **固定成型**：热熔胶把舵机摇臂粘到风扇立柱做摇头支架；整板焊到洞洞板更耐造。
7. **软件联调**：
   - 串口：控制中心「串口设备」选 COM 口连接。
   - WiFi：固件改 `FLOWCC_TRANSPORT WIFI`，填 `WIFI_SSID/WIFI_PASS` 烧录；
     串口监视器看 IP；软件「WiFi 设备」填 IP + 3333 连接。
   - 蓝牙：固件改 `FLOWCC_TRANSPORT BLE` 烧录；软件「蓝牙设备」扫描 FlowCC 连接
     （源码版需 `pip install bleak`）。
8. **验收清单**：开关机 / 三档 / 摇头 / 手动摆头 / 定时关机 / 掉线提示，逐项打勾。

## 四、安全须知

- 通电前逐项核线；短路会烧 MOSFET/ESP32，但低压无触电风险。
- 续流二极管与栅极下拉电阻不可省略。
- 12V 风扇必须独立供电并与 ESP32 共地，勿从板载 5V 引脚取大电流。
- 长期无人值守：供电回路串 1A 保险丝，风扇放平稳无遮挡处。

## 五、常见问题

| 现象 | 排查 |
|---|---|
| 找不到串口 | 换数据线；装 CH340 驱动；设备管理器看 COM 号 |
| 连接超时 | 波特率 115200；固件已烧录；WiFi 版确认同网段与 IP |
| 风扇不转 | `PWR 1` 后量 MOSFET 漏极电压；核对共地与二极管 |
| 上电自转 | 栅极 10kΩ 下拉缺失或虚焊 |
| 舵机抖动 | 5V 供电不足，改独立 5V 并共地 |
| 蓝牙扫不到 | 固件为 BLE 版；手机/电脑蓝牙已开；距离 <5 米 |

完成后即可在桌面挂件上享受你的智能风扇。遇到问题把串口监视器输出发回，便于定位。
