# FlowCC 3.0.0 发布说明

全新版本基线，基于 v2.2.13 稳定状态发布。

## 里程碑

- 版本管理重构：历史版本（v1.0.0~v2.2.13）全部归档至 docs/历史版本记录.md，
  仅保留 3.0.0 及后续 3.0.x / 3.1.x 版本线
- macOS 完整支持：安装指南、.icns 图标、GitHub Actions 自动构建、本地打包脚本

## 功能集合（继承自 v2.2.13）

- 桌面透明挂件为主交互入口（真逐像素透明，Windows / macOS 双平台）
- 四种连接：模拟设备 / USB 串口 / WiFi（TCP 3333）/ 蓝牙 BLE（NUS）
- 3D 经典渲染：前网罩椭圆透视、真实风扇启停动画（S 形加速 + 惯性滑行 + 启动颤振）
- 送风模式：恒定风 / 自然风 / 睡眠风；定时关机；手动摆头（←/→ 方向键）
- 风声模拟：按档位循环播放（winsound 合成，无版权风险），可一键静音
- 跨平台数据目录与配置持久化

## 下载

- Windows：FlowCC-Setup-3.0.0.exe（下一步式中文安装向导）
- macOS：GitHub Actions 构建产物（FlowCC.app，zip 包）
